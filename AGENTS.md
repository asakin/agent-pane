# Agent Pane

Agent Pane runs a real local terminal (and coding agents on `PATH`) inside Chrome's side panel. It has two parts: a Go native-messaging host and PTY server at the repository root, and a WXT (Manifest V3) browser extension in `extension/`.

## Essential knowledge

- **Working directory:** Run every command below from the repository root (pass `--prefix extension` to `npm`, or `cd extension` first).
- **Stack:** Go (version in `go.mod`) for the native host and PTY server; TypeScript, WXT, and `@xterm/xterm` 6 in `extension/` (tested with `node --test tests/*.test.mjs`).
- **Adding a native-messaging RPC method:** define request/response types in `extension/entrypoints/shared/rpc.ts`, forward the method through `sendNative` in `extension/entrypoints/background.ts`, handle it in `internal/cmd/serve.go`, and cover both sides in `extension/tests/nativeRpc.test.mjs` and `internal/cmd/agents_test.go`.
- **Adding an agent definition:** create `agents/<id>/agent.json` and `icon.svg` (or `icon.png`); copy `agents/pi/agent.json` as a starting point.

## Do not touch

- **Generated themes:** `internal/cmd/themes/` is generated by `deno run -A scripts/refresh-themes.ts`. Do not hand-edit files in `internal/cmd/themes/`.
- **Extension permissions:** keep `extension/wxt.config.ts` free of page `host_permissions` and content scripts (`README.md`).
- **Default agent enablement:** adding `agents/<id>/` leaves that agent disabled by default until its id is listed in `agents/enabled.json` (`agents/README.md`).

## Commands

Run both check suites before pushing (matching `.github/workflows/ci.yml`):

### Go backend (from repository root)

```sh
gofmt -l .
go vet ./...
go test -race ./...
go build ./...
```

When changing `install.sh`, also run:

```sh
./install_test.sh
```

### Extension (from repository root)

```sh
npm --prefix extension ci
npm --prefix extension run compile
npm --prefix extension test
npm --prefix extension run build
```

## Map

- `main.go`, `internal/cmd/`: Go CLI entry point, native-messaging host (`serve.go`), agent catalog loader (`agents.go`), and macOS LaunchAgent spawn (`spawn_darwin.go`).
- `internal/jsonrpc/`, `internal/scrollback/`: JSON-RPC framing and terminal scrollback ring/mode replay.
- `extension/entrypoints/`: WXT extension entry points (`background.ts`, `sidepanel.html`, `options.html`) and shared terminal/tab/RPC modules in `extension/entrypoints/shared/`.
- `extension/tests/`: Node test runner suites (`*.test.mjs`).
- `agents/`: shipped agent definitions and `agents/enabled.json`; see [agents/README.md](agents/README.md).
- `install.sh`, `install_test.sh`: curl installer and its test script.
