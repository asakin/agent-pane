# Security policy

Agent Pane runs local shells and coding agents with your user account's permissions. It is experimental software, not a sandbox. Read the [security model and limitations](README.md#security) before using it.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/asakin/agent-pane/security/advisories/new). Do not post exploit details, credentials, terminal contents, or private page data in a public issue.

Include the affected version or commit, operating system and browser versions, reproduction steps, the expected security boundary, and the impact. A minimal proof of concept with synthetic data is helpful.

Security fixes target the current `main` branch and future releases. Historical Agent Terminal releases are preserved for provenance and are not maintained by this project. There is no separate support commitment for older versions or guaranteed response time.
