Settings

Used instead of Theme while Chrome is in dark mode. The side panel's Settings button offers five popular dark themes; this page lists every bundled theme.

Built-in runs pane tabs in the native host, as before. Durable (preview) runs new pane tabs in the terminal runtime bundled with Agent Pane. In this preview, pane tabs still end when Chrome or the host closes, and page reads use only the pane tab's page socket. If Durable cannot start a pane tab, it runs in Built-in and says why in the terminal. Applies to pane tabs opened after saving.

Agents and Send tab never read pages on these domains, even in a pane tab that already has approval. An entry such as bank.example also blocks its subdomains, such as login.bank.example, but not notbank.example or bank.example.evil.test. Ports and letter case are ignored. Changes save at once and apply to open pane tabs.

    Browser control

    Agents can click, type and navigate in your Chrome with a browser-control tool. Agent Pane does not control the browser; these tools do, with their own Chrome extensions and their own warnings. Using one is your choice and your responsibility. Agent Pane's page-read approvals and blocked domains apply to agent-pane page only: an agent with one of these tools can act on any tab you connect to it.

    Nothing here installs anything. Run a command in a pane tab, or ask the agent to; only you can add a Chrome extension. agent-pane setup browser prints the same report in a terminal.
