Settings

Built-in runs pane tabs in the native host, as before. Durable (preview) runs new pane tabs in the terminal runtime bundled with Agent Pane. In this preview, pane tabs still end when Chrome or the host closes, and page reads use only the pane tab's page socket. If Durable cannot start a pane tab, it runs in Built-in and says why in the terminal. Applies to pane tabs opened after saving.

Agents and Send tab never read pages on these domains, even in a pane tab that already has approval. An entry such as bank.example also blocks its subdomains, such as login.bank.example, but not notbank.example or bank.example.evil.test. Ports and letter case are ignored. Changes save at once and apply to open pane tabs.
